# Cyber Shield — درع الحماية

موقع عربي بواجهة بيضاء ومتجاوبة مع الجوال، يسمح بإرسال رابط إلى VirusTotal وعرض نتيجة الفحص بالتصنيفات التالية:
- 🟢 لم تُرصد مؤشرات خطيرة
- 🟡 مشتبه به أو النتيجة غير حاسمة
- 🔴 خطير

يتضمن الموقع عبارة التذييل: **صنع الطالب: يزن**.

## مهم قبل الاستخدام

الموقع يحتاج إلى مفتاح API من VirusTotal حتى ينفذ فحصًا حقيقيًا. من دون المفتاح سيعرض رسالة واضحة، ولن يدّعي أن الرابط نظيف.

## التشغيل على الكمبيوتر

1. ثبّت Node.js إصدار 18 أو أحدث من الموقع الرسمي: https://nodejs.org/
2. فك ضغط ملف ZIP وافتح مجلد `cyber_shield`.
3. افتح Terminal أو موجه الأوامر داخل المجلد.
4. نفّذ الأمر: `npm install`
5. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
6. افتح `.env` وضع مفتاح VirusTotal مكان `ضع_مفتاحك_هنا`:
   `VIRUSTOTAL_API_KEY=مفتاحك_هنا`
7. شغّل الموقع: `npm start`
8. افتح المتصفح على: `http://localhost:3000`

## نشر الموقع على الإنترنت

ارفع ملفات المشروع إلى منصة استضافة تدعم Node.js (مثل Render أو Railway أو خادمك الخاص)، واضبط متغير البيئة `VIRUSTOTAL_API_KEY` من إعدادات الاستضافة. لا ترفع ملف `.env` ولا تضع المفتاح في ملفات الواجهة الأمامية.

## كيف يعمل الفحص؟

- يرسل الخادم الرابط إلى واجهة VirusTotal API.
- يستعلم الخادم عن حالة التحليل حتى تكتمل النتيجة.
- يعرض الموقع إحصاءات المحركات تحت «خطير»، «مشبوه»، «لم يرصد ضررًا» و«غير محسوم».
- إذا تعذّر الفحص أو كانت النتيجة غير مكتملة، لا يعرض الموقع نتيجة خضراء على أنها فحص مؤكد.

## ملاحظات

- قد تكون لحساب VirusTotal حدود استخدام، وقد يستغرق التحليل وقتًا.
- إرسال الرابط إلى VirusTotal يعني مشاركته مع خدمة خارجية؛ لا تستخدم الموقع لإرسال روابط خاصة أو تحتوي على رموز سرية.
- لا توجد خدمة تستطيع ضمان اكتشاف كل الروابط الضارة. حتى النتيجة الخضراء ليست ضمانًا مطلقًا.
- توجد حماية بسيطة لتقليل كثرة الطلبات، لكن أي نشر عام يحتاج إلى حماية أقوى ومراقبة استخدام مناسبة.
